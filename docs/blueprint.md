# **App Name**: RiceWise AWD

## Core Features:

- User Management: User registration and role-based dashboards for farmers, field agents, supervisors, local partners, and Aurigraph representatives.
- Plot Registration: Plot registration with hectare details, property records, and photo uploads, followed by approvals from Field Agents and Supervisors.
- Reporting Hierarchy: Hierarchical reporting structure: Farmers -> Field Agents -> Supervisors -> Local Partners -> Aurigraph Spox.

## Style Guidelines:

- Primary color: Earthy Green (#388E3C) to represent agriculture and sustainability.
- Secondary color: Light Beige (#F5F5DC) for a clean and neutral background.
- Accent: Golden Yellow (#FFC107) for highlighting key information and calls to action.
- Clean and intuitive layout with clear navigation for different user roles.
- Use simple, recognizable icons to represent different data points and actions.
